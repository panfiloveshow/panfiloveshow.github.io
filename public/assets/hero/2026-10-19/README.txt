SELLICO — 3 баннера нового главного экрана

Формат: Hero, квадрат 1:1, 1254×1254 px.
Файлы: JPG/PNG/WebP принимаются новой админкой; здесь подготовлены WebP по 137–152 КиБ, каждый значительно меньше лимита 5 МБ.
Мобильный файл можно не задавать: главное изображение уже квадратное.

01-profit.webp — прибыль по SKU, ссылка /unit-economics/, порядок 10.
02-stock.webp — остатки и поставки, ссылка /supply-planning/, порядок 20.
03-team.webp — задачи команды, ссылка /#demo, порядок 30.

Название, alt-текст, ссылки и порядок приведены в banners.json. JSON — памятка по полям, автоматический импорт админкой не заявлен.

Загрузка: Админка → Баннеры → Новый баннер → Формат Hero → файл WebP → название/ссылка/alt/порядок → Сохранить. Даты можно оставить пустыми.

На присланном скриншоте открыта старая опубликованная версия с широким форматом 4800×640. Для этих файлов сначала должна быть опубликована новая CRM и обновлён API с миграцией format. Загрузка через старую форму создаст запись strip и не добавит её в новый hero.

Баннеры показывают функции сервиса без скидок и вымышленных результатов. Изображения созданы встроенным image_gen по выбранному пользователем стилю.
