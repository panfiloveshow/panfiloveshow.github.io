# ТЗ для бэка: промо-баннеры на главной sellico.ru

## Что нужно

Слайдер баннеров на лендинге (sellico.ru, блок «Весна продаж») переведён на картинки.
Фронт уже готов: при загрузке страницы он делает `GET /api/public/promo-banners` и, если пришёл непустой список, показывает баннеры-картинки. Если эндпоинта нет / список пуст / ошибка — показывает старые текстовые слайды. Ничего не сломается, можно выкатывать бэк независимо.

Нужно на стороне основного бэка Sellico (/var/www/html/backend):

## 1. Админка: раздел «Промо-баннеры (лендинг)»

CRUD со следующими полями:

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| `title` | строка | да | внутреннее название, на сайте не показывается |
| `image` | файл-картинка | да | desktop-версия |
| `image_mobile` | файл-картинка | нет | версия для экранов < 640px; если нет — используется desktop |
| `alt` | строка | нет | alt-текст картинки (доступность/SEO) |
| `link` | строка (URL) | нет | куда ведёт клик по баннеру; пусто = баннер некликабельный |
| `sort_order` | целое | да, default 0 | порядок в слайдере, меньше = раньше |
| `is_active` | bool | да, default true | выключенные не отдаются в API |
| `active_from` | datetime | нет | начало показа (для акций) |
| `active_until` | datetime | нет | конец показа |

Валидация загрузки:
- форматы: jpg, png, webp; размер файла ≤ 5 МБ;
- в форме подсказать рекомендуемые размеры (см. п. 3).

Хранение: публичный storage, отдавать абсолютные URL (`https://sellico.ru/storage/...`). Ресайзить/конвертировать на сервере не обязательно — админ загружает готовый баннер нужного размера.

## 2. Публичный API

`GET /api/public/promo-banners` — без авторизации, тот же домен, что и лендинг (CORS не нужен).

Отдаёт только `is_active = true` и попадающие в окно `active_from/active_until` (null = без ограничения), сортировка по `sort_order`, затем `id`.

Формат ответа (фронт понимает и голый массив, и обёртку `{"data": [...]}`):

```json
{
  "data": [
    {
      "id": 1,
      "image": "https://sellico.ru/storage/promo-banners/spring-2400x320.webp",
      "image_mobile": "https://sellico.ru/storage/promo-banners/spring-1125x375.webp",
      "link": "https://sellico.ru/crm/register",
      "alt": "Весна продаж: 3 + 1 месяц в подарок"
    }
  ]
}
```

Кэш: можно отдавать с `Cache-Control: public, max-age=300` — баннеры меняются редко.

## 3. Размеры картинок (для подсказки в админке)

Фронт рендерит баннер на всю ширину плашки с `object-cover` (лишнее по краям обрезается по центру):

- **Desktop** (≥ 640px): соотношение **15:2**, рекомендуемый размер **2400 × 320 px**;
- **Mobile** (< 640px): соотношение **3:1**, рекомендуемый размер **1125 × 375 px**.

Формат — лучше webp (легче), jpg/png тоже ок.

## 4. Что НЕ нужно

- Никакой статистики показов/кликов.
- Никаких текстовых полей для рендера поверх картинки — весь текст рисуется в самой картинке дизайнером.
- Автогенерация ресайзов — не нужна, грузим готовые размеры.
